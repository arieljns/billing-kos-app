# Billing Kos App Constitution

## Core Principles

### I. User Experience
The project must have a simple UX and UI, specifically designed for users with low digital literacy. Focus on intuitive navigation and clear visual cues.

### II. Minimal Dependencies
The project must have minimal dependencies on external libraries to ensure a lightweight and maintainable codebase.

### III. Mobile First
The application must be developed with a mobile-first approach, ensuring optimal performance and user experience on mobile devices.

### IV. Reusable Components
Utilize React reusable components for consistent UI and faster development. Components should be atomic, well-defined, and easily testable.

### V. Separation of Concerns
Maintain a clear separation of concerns between layout components, state management, and API calling logic for better organization and maintainability.

### VI. Optimistic UI
Implement an optimistic UI to provide immediate feedback to users, enhancing the perception of responsiveness and improving the overall user experience.

## Additional Constraints

The project must adhere to modern web development standards and best practices.

## Development Workflow

All code must be reviewed and pass automated tests before merging.

## Governance

This constitution supersedes all other practices. Amendments require documentation, approval, and a migration plan.
